# SPACE-RELICS
Project summary
NASA’s Space-Time Capsule: The Hardware We Left Behind

Since the 1960s, NASA spacecraft have explored the Moon, Mars, and beyond. Some have stopped working, some still send data, and others are continuing their journeys through deep space. This project tells the stories of these machines: what they were built to do, what they discovered, and what their journeys can teach us about exploring safely and thoughtfully
